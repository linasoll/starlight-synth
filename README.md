# ₊˚⊹☆⋆♫ Starlight Synth ♫⋆☆⊹˚₊ 

Starlight Synth — инструмент для создания расслабляющих эмбиент-композиций, вдохновлённых звучанием ханга и атмосферой ночного дождя. Синтезатор позволяет создавать музыку для отдыха и засыпания.

В проекте используются шесть звуковых дорожек: Melody, Harmony, Hi-Hats, Bass High, Bass Low и Rain. Для отдельных партий доступны дополнительные настройки.
